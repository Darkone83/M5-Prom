A LITTLE HELP

Before you flash.

One browser, one cable.
Here are the details that matter.

Which Cardputer is this for?+

The original M5Stack Cardputer and Cardputer v1.1 with an ESP32-S3 and 8 MB flash. This firmware is not for Cardputer ADV. The installer checks the chip and flash size; select the correct physical board.

My Cardputer does not appear. What next?+

Use a USB data cable and close M5 Prom Remote, M5Burner, Arduino serial monitors and any other application using the port. The running M5 Prom Remote interface is different from the ROM serial bootloader.

Hold G0 / BOOT, tap RESET, then release G0. Alternatively, hold G0 while connecting USB power, then release it. Reconnect in the installer and select the new USB serial port. You only need to hold G0 while entering download mode.

M5Stack download-mode guide ↗
Will this erase my EEPROM backups?+

No. This updates the Cardputer’s internal firmware. It does not access the microSD card or program an Xbox EEPROM. The supplied layout also leaves the Cardputer’s saved-settings partition untouched. Disconnect the Xbox adapter while updating firmware.

What if an installation is interrupted?+

The installer stops and reports the failed stage. Put the Cardputer back into download mode, reconnect, and explicitly start the installation again. A failed write is never automatically retried as a complete installation.

Which browser should I use?+

Use desktop Chrome or Microsoft Edge over HTTPS. The installer checks whether this browser exposes Web Serial before offering a connection. Safari and Firefox do not provide the required native Web Serial interface.
